# 音频文件清理工具

一个 macOS 桌面小工具，用于批量整理音频文件夹：

1. **选择指定文件夹** —— 点击“选择文件夹…”，工具会自动扫描该层目录下的全部音频文件
2. **清除音频文件属性** —— 删除文件的标签元数据（标题、歌手、专辑、封面等），支持 MP3 / WAV / FLAC / M4A / OGG 等常见格式
3. **清除文件名中的无效信息** —— 自动去除前导编号（`01`、`02`、`03-138` 等）、空括号（`[]`、`【】`、`(01)` 等）以及开头结尾的多余符号
4. **清除多个文件名中的类似项** —— 自动检测所有文件共同包含的片段（例如 `【taoqu98】`），也支持手动输入要删除的片段

## 运行方式（二选一）

### 方式一：直接使用打包好的 App（推荐）
双击 `dist/音频文件清理工具.app` 即可使用，无需安装任何环境。

### 方式二：源码运行
双击 `启动音频文件清理工具.command`（首次运行会自动安装依赖），
或在终端执行：

```bash
cd 音频文件清理工具
python3 main.py
```

依赖：`pip3 install mutagen`（Python 3.9+）

## 使用步骤

1. 点击 **选择文件夹…**，选择存放音频文件的文件夹（自动扫描，不会进入子文件夹）
2. 勾选需要的处理选项：
   - **清除音频文件属性**
   - **清理文件名**
   - 在“类似项”列表中确认要删除的公共片段（自动检测的已默认选中），也可手动输入片段后点 **添加**
3. 点击 **预览改动** —— 右侧列表展示每个文件“原文件名 → 新文件名”，**点击行首可取消个别文件**
4. 核对无误后点击 **开始处理**，日志区会逐条显示处理结果

## 文件名清理规则

| 规则 | 示例 |
|---|---|
| 删除公共类似项 | `...【taoqu98】.mp3` → 去掉 `【taoqu98】` |
| 删除前导编号 | `01 Crazy Frog...` → `Crazy Frog...`；`03-138 She Got It...` → `She Got It...` |
| 删除空壳/纯编号括号 | `[]`、`【】`、`(01)` 整体删除 |
| 清理首尾多余符号 | `- 标题 -` → `标题`；连续空格压缩为单个 |
| 防重名保护 | 若新文件名与已有文件冲突，自动追加 `(1)`、`(2)` |

> 括号内容（如 `(Fox boot)`、`(T9 bootleg)`）默认保留；扩展名保持不变。

## 注意事项

- 只处理所选文件夹**当前层**的文件，不递归子文件夹
- 清除元数据为**不可逆操作**，且会重写音频文件本身（仅标签部分，不影响音频数据）；处理前建议先备份重要文件
- 所有改名操作都会先预览，确认后才执行
- 无标签的文件会被跳过并提示“本就没有标签”，不会报错
